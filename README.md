
# Expense Tracker Backend

A RESTful Expense Tracker application backend developed using Java, Spring Boot, and MySQL.

## About the Project

Expense Tracker Backend is a Java-based Spring Boot application designed to manage users, categories, transactions, and budgets.

## Technologies Used

- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST APIs

## Features

- User Management
- Category Management
- Transaction Management
- Budget Management
- CRUD Operations
- RESTful API Architecture

## Project Structure

- Model
- Repository
- Service
- Controller

## Database

MySQL

Database Name: `exp_backend`

## How to Run the Project

1. Clone the repository.
2. Open the project in Spring Tool Suite or IntelliJ IDEA.
3. Configure your MySQL database in `application.properties`.
4. Run the Spring Boot application.
5. The application will start on port `8080`.
